## 子项目一：批改中断恢复

### 用户流程

- 批改发送前，将题目、原答、实际量表、方法及参考依据快照保存为本机任务记录。
- 按评分、评分已落库、修改稿生成、完成、失败或取消记录阶段。模型评分落库与任务关联必须在同一事务内完成，不能依赖界面回调猜测是否已评分。
- 软件重新启动后，在现有页面提供简洁的“未完成任务…”入口，显示题目、时间和阶段。不自动打开收费请求。
- 选中任务，可查看、继续或放弃。继续前说明使用的是当时输入快照、当前已保存的模型设置以及可能再次计费，默认取消。
- 原答评分已保存时，只继续生成修改稿；已完成任务只打开报告，不重复发送。
- 尚未保存评分时，提示上次请求的服务端执行状态未知，用户确认后从评分阶段重试。不能承诺服务端恰好执行一次或无重复收费。
- 主动取消的任务不自动恢复；用户仍可从列表明确选择继续或放弃。放弃不删除已保存报告。

### 数据和并发

新增独立任务表，通过稳定任务 ID 关联训练记录，保存格式版本和提示版本。快照按允许字段保存，不复制密钥或完整网络请求。跨重启恢复前重新验证内容、提示兼容性和记录状态。

同一任务的运行占用、阶段更新和报告关联使用数据库条件更新及事务保护。多个窗口不能同时领取同一任务；启动另一个窗口不能把仍由活跃窗口执行的任务直接判为中断。失去运行占用的旧回调不能覆盖新结果。

删除相关训练记录后，任务不能重新创建该记录；恢复列表刷新会将关联失效任务标为不可继续。数据库恢复后不得沿用恢复前的内存回调或运行占用。旧版备份没有任务表时按迁移补建空表。

### 实现边界与验证

现有评分入口在 `service.py`，UI 入口和重试在 `ui/assessment.py`；新增任务存储和列表模块，避免继续把状态机堆进界面函数。复用现有 `retry_revisions` 的内容核对和并发保护。

验证覆盖：发送前失败、评分阶段失败、评分保存后退出、修改稿失败或取消、重启继续、已完成再点继续、多窗口争抢、删除后继续、旧备份迁移、任务损坏或提示版本不兼容。离线模拟模型调用，断言已存评分不再调用评分接口，取消确认时零调用。

## 子项目二：可视化训练量表

### 用户流程

- “参考与量表”保留考试类别模板选择和“预览实际量表”，右侧默认以表格显示维度名称、权重、说明，可添加和删除。
- 选择内置模板时先展示实际解析结果；用户明确点击“编辑为自定义”才建立自定义内容，不能因为渲染表格就把内置模板改成自定义。
- 自定义量表仍沿用原有 `rubric_text` / JSON 契约。维度 ID 在编辑已有行时保留，新增行生成稳定 ID，重命名不会换 ID。
- “高级 JSON…”作为单独入口保留。打开或取消对话框不改变内容；确认后校验并同步表格。无效、未完成的旧 JSON 保留原文，不自动替换成模板。
- 切换考试、题型或模板不覆盖自定义内容。恢复模板须明确确认，不静默清除自定义文字。
- 显示简短权重合计。沿用原有 1—20 维度、权重 0—100、合计 100、名称非空和 ID 唯一规则。未完成编辑可保存草稿，但不能用于批改。
- 参考答案输入框以及此前统一的四个文本框占位文字保持不变。

### 实现边界与验证

新增量表表格/对话框模块接入 `ui/assessment.py`。复用 `domain.validate_rubric`、模板解析、原有自动保存和提交规则，不引入第二套评分规则。保留内部 JSON 状态以兼容既有草稿和测试。

验证覆盖：模板展示不变更来源、自定义编辑与重启恢复、新增/删除及 ID 保留、小数权重合计、无效 JSON 原文保留、切换模板不覆盖、取消不改变草稿、批改实际权重、最小 1050×720 窗口。此功能不调用模型。

## 子项目三：自动备份与恢复管理

### 默认行为

- 每个本地自然日首次正常使用时，在界面初始化完成后后台备份一次；软件跨日持续打开时，下次空闲检查补做当天备份。不在每次启动或每次自动保存时复制完整数据库。
- 默认自动备份目录为本机软件数据目录下的 `backups`，默认保留最近 7 份日常自动备份。设置中可关闭、修改保留数量（1—30）及选择目录。
- 自动备份复用 SQLite 一致性备份与完整性检查。成功写成后才记录当天成功状态；失败保留已有备份，不淘汰旧文件，显示简短失败状态并允许手动重试。
- 大数据库在后台执行，界面不因复制阻塞；同一数据库多窗口互斥备份。备份中的任务恢复为待确认状态，不在还原后自动调用模型。
- “备份管理…”列出应用登记的备份，显示日期、大小、类型，可打开所在目录或选择恢复。恢复继续使用现有覆盖确认、恢复前安全备份和失败回滚。

### 备份保留与安全

- 只清理已登记、身份与目录校验通过的本应用日常自动备份；不扫描删除目录里的任意 `.db`，不递归清空用户目录，不跟随符号链接/重解析点清理。
- 手动备份、恢复前安全备份不参与日常自动淘汰。自动轮换会删除超过保留数量的旧自动备份，应在设置中明确告知；恢复前安全备份由用户自行管理。
- 选择新目录不搬移、不删除原目录的备份。来自恢复文件的外部备份目录设置须重新确认后才能向该位置自动写入。
- 默认本机目录内备份随既有“完全卸载”规则清理；用户主动选择的外部备份作为独立用户文件保留，卸载不递归删除外部目录。管理界面明确显示此差异。
- 系统凭据库密钥不进入备份；拒绝或脱敏含认证信息的新增元数据，备份仍含题目和报告等私密学习资料，不宣传为加密备份。

### 实现边界与验证

复用 `practice_store.backup_to` / `restore_from`，新增自动备份协调和目录清单模块，设置页接入管理对话框。清单使用应用独立标识，不信任仅凭文件名匹配的数据库。

验证覆盖：同日去重、跨日补备份、并发互斥、磁盘不可写与失败重试、完整性失败不轮换、仅清理应用登记文件、外部文件及安全备份保留、恶意路径/链接拒绝、目录变更、恢复前备份与恢复失败回滚、旧数据库兼容。此功能不调用模型。
