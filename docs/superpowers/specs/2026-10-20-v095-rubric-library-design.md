# 0.9.5 子项目二：自定义量表模板库

状态：用户已确认细化设计。共同约束见 `2026-10-20-v095-design.md`。

## 现有接口与选择

保留 `ui/rubric_editor.py` 的原始 JSON 单一权威状态、无损数字文本、稳定维度 ID 和高级 JSON 入口；继续使用现有 `validate_rubric` 与内置模板解析，不新建评分规则。

采用独立本机模板记录，不将命名模板当作动态评分引用。载入模板时复制内容到当前自定义草稿；之后库中修改或删除不影响已经载入的副本、进行中的批改、旧报告或任务快照。

## 用户流程

- 在现有模板选择区域增加“模板库…”入口；不另加主页或常驻说明，不挤占维度表。
- “保存当前…”要求当前量表校验通过，填写 1—60 字的名称并指定适用题型，保存一份命名快照。
- 保存内置量表快照本身不把当前草稿变成自定义；只有明确选择“载入”才修改当前编辑器。
- 模板列表可按名称和题型筛选；支持载入、复制、重命名、更新内容和删除。更新现有模板是独立显式操作，不能因编辑当前量表而自动回写库。
- 名称去除首尾空格后按不区分大小写的规范化键去重；重名时提示改名，不静默覆盖。复制要求新名称。
- 当前已有自定义内容时，载入其他模板或恢复内置模板前明确确认，默认取消；取消保持原始 JSON 逐字不变。
- 删除只删除库记录，默认取消确认；已载入副本和历史报告保留。不引入模板回收站，误删可通过用户保留的数据库备份恢复。

## 数据与并发

- 新增独立 SQLite 模板表，记录稳定 UUID、规范化名称键、展示名称、适用题型、原始 JSON 字符串、版本、创建/更新时间。载入自定义模板不重排或重新序列化原始 JSON，不丢失未修改数字、未知字段或维度 ID。
- 保持模板原始内容与编辑器原始 JSON 可逐字往返；校验只确认可用性，不用规范化后的浮点值覆盖原文。无效量表可继续作为原草稿保存，但不能作为有效模板入库。
- 列表渲染/筛选/查看不改草稿，载入前再次核对最新记录。重命名、更新与删除使用版本检查；记录已被其他窗口改动或删除时拒绝旧写入，不重建已删模板。
- 所有模板管理和载入确认均绑定打开前的数据库恢复代际。恢复后旧对话框失效，保留输入并要求重新载入，不能采用恢复前的授权。
- 对外只存允许的模板字段，不复制模型设置或凭据。

## 备份兼容

- 新模板表由普通/自动/安全 SQLite 备份共同保存；恢复前校验其结构、名称唯一性、类型、版本及量表内容。
- 旧数据库首次升级创建空模板库；缺少模板表的旧备份仍可还原，还原后模板库为空，不凭旧界面缓存重新补造。
- 改动恢复校验时保持 0.9.4 的任务状态、复习计划、自动备份本机登记与恢复回滚行为。模板读写不触发模型，也不修改已存分数。

## 验证

- 新建、按题型筛选、重命名、复制、更新、删除、重启保存与名称冲突；列表操作不修改当前草稿。
- 内置模板保存不改变 builtin 身份，明确载入才生成自定义副本；无效 JSON 拒绝保存且原草稿不丢。
- 高精度数字、未知嵌套字段、稳定 ID、格式空白逐字往返；修改/删除库记录不改变已载入草稿或旧报告。
- 覆盖确认取消、并发改删、恢复期间确认及过期管理窗口不会静默覆盖/重建。
- 新备份还原库、旧备份还原为空、损坏模板拒绝恢复且当前数据库保留/回滚；新增功能模型调用数为 0。
- 正常与 1050×720 最小窗口中入口、表格和原高级 JSON 按钮可用，原提示小字不重新出现。
