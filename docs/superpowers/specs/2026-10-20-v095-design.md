## 本轮范围

1. [导入内容分配](2026-10-20-v095-intake-routing-design.md)：导入/识别后的文字按段分配到四个输入栏，分别预览、默认追加、覆盖确认。
2. [自定义量表模板库](2026-10-20-v095-rubric-library-design.md)：命名保存、按题型复用、复制、重命名、删除；历史报告不受影响，模板随备份保存。
3. [复盘建议转复习计划](2026-10-20-v095-review-goals-design.md)：勾选已保存报告的优先改进项，加入已有复习计划，保留来源摘录；状态仍由用户确认。

三个模块各有独立实现计划与测试，依次完成，最后统一验收。多模型配置、训练统计、自动分段分类及额外 AI 调用不在本轮范围。

## 选择的实现方式

- 采用增量扩展：复用现有导入预览、原始量表 JSON、SQLite 工作区与复习计划。不建立第二套评分或任务系统。
- 不采用模型自动分配/生成计划：会增加费用和误分类风险，偏离已确认的本机处理范围。
- 不重做主界面或新建独立训练平台：保留六个工作区，只增加必要按钮、菜单和对话框。

## 共同约束

- 以 `E:\ShenlunStudio\ShenlunStudio-0.9.4-Project` 为只读基线；保留既有 0.9.4 项目、便携版和安装包。
- 主界面配色、布局风格、四个输入框占位文字及已精简提示保持不变，不新增常驻解释小字；覆盖、删除、费用和私密数据等必要确认保留。
- 输入字符、单次输出 token、任务 token 预算可设置最大值仍为 9,999,999，不擅自修改默认值。本轮不顺带放宽既有导入、草稿等安全容量限制。
- 新增分配、模板和计划操作不调用模型；现有 OCR/AI 转写流程及上传确认保留。不能借这些新增入口触发后台收费请求。
- 历史评分快照、原答、修改稿和人工评分不被重写；删除题目/报告后的失效关联不得静默重建。
- 新数据只保存在本机 SQLite 与其备份中，不保存 API 密钥、认证头或完整模型配置。模板与复盘目标均含用户内容，不宣传为加密存储。
- 所有新增可写对话框在数据库恢复后失效，保留待处理输入并要求重新载入；并发修改通过版本或快照比较拒绝覆盖，不能依赖只检查界面状态。
- 继续使用 0.9.4 的安全备份、恢复回滚、后台线程收尾、任务占用及恢复代际机制。备份登记与自动备份设置仍为机器本地数据。
- 不实际安装、卸载或操作日常用户数据库；开发、测试和截图使用独立副本与合成数据。不初始化 Git，也不删除之前的审计资料。
