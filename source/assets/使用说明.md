# 申论研习使用说明

适用版本：1.0.1

申论研习是一款本地运行的申论训练工具。它把题目导入、原答保存、训练批改、评分依据核对、文章与方法积累、复盘记录放在同一个桌面软件中。软件不会自动调用模型，也不会在后台修改你的原答。

> 训练估分是学习反馈，不是官方阅卷结果，也不构成提分承诺。AI 输出、OCR 识别和材料引用都需要你对照原文核对。

## 一、安装与启动

1. 双击 `ShenlunStudio-1.0.1-Setup.exe`，按安装向导完成安装。
2. 从桌面快捷方式或开始菜单启动“申论研习”。
3. 首次启动会自动创建本地数据库，无需注册账号。
4. 卸载程序会清理安装目录和默认数据目录。若你把备份放在其他位置，那些备份不会被自动删除。

默认数据目录：

```text
%LOCALAPPDATA%\ShenlunStudio
```

其中 `studio.db` 保存题目、文章、方法、训练记录和设置。模型密钥不写入这个数据库。

安装目录中另附一份 `使用说明.md`，可在不启动软件时阅读。

## 二、首次设置模型

模型只用于批改、修改稿、批注复核、文章提炼等需要理解文字的操作。检索文章、浏览题库、查看旧报告和本机 OCR 不消耗模型调用。

1. 打开左侧“设置”。
2. 填写接口地址、模型名称和 API 密钥。
3. 如需控制费用，同时设置单次输出上限或调用预算。
4. 点击“测试连接”。通过后保存。
5. 返回“训练批改”，顶部状态会显示当前模型。

密钥保存在 Windows 凭据库或当前会话中，不写入文章与训练数据库。批改和提炼时，软件会把完成该次操作所需的内容发送给你配置的模型服务。发送前会显示范围与预计用量；取消操作不会撤回服务端已经产生的费用。

更换模型后，建议先用一题做小额测试，核对返回格式、分项评分和修改稿是否符合预期。兼容性测试只说明接口能否工作，不代表评分准确。

## 三、快速开始

第一次使用可按以下顺序完成一次训练：

1. 在“训练批改”导入题目、材料和自己的原答。
2. 核对题型、考试、年份、类别与字数限制。
3. 选择训练量表；没有把握时保留自动匹配，并点“预览实际量表”。
4. 选择批改方式：只生成精批，或同时生成修改稿。
5. 点击“开始训练批改”，确认发送范围和预计用量。
6. 在“复盘重点”“训练报告”“评分依据”“原答与批注”之间对照阅读。
7. 需要时生成修改稿、复核批注、加入复习或导出报告。
8. 在“我的题库”保存题目，在“训练记录”回看历史。

## 四、导入题目与原答

“训练批改”的“01 题目与原答”支持：

- 导入 Word、PDF 或图片；
- 从剪贴板粘贴文字；
- 导入已有原答；
- 载入软件自带练习示例；
- 保存草稿、恢复草稿和继续未完成任务。

导入后会出现页面预览。勾选需要写入的页面，可修改文字、调整顺序或移除；只有确认后才写入编辑区，取消不会改动当前内容。图片识别在本机运行，但手写、表格、专名和数字仍可能识别错误，请对照原图核对。

### 字段说明

- 题型、考试、年份和类别：用于匹配训练量表，也影响复盘统计。
- 字数限制：用于检查原答长度和修改稿长度。
- 题干：题目要求。缺少题干或材料时，软件只做表达与结构诊断，不生成完整题目分数。
- 给定材料：批改时用于核对材料依据。材料段落编号会出现在评分依据中。
- 原答：本次要批改的作答。原答与后续修改稿分开保存。
- 参考答案：可选。它用于辅助复盘，不会替代你的原答。

编辑过程中草稿会自动保存。若保存失败，底部会出现“重试保存”；关闭软件前建议确认状态为已保存。

## 五、参考与训练量表

“02 参考与量表”包含参考答案和训练量表。

- 自动匹配会依据考试、类别和题型选择模板。
- 可手动选择模板；手动模板与考试、类别不一致时，预览中会提示适用边界。
- “预览实际量表”显示维度、权重、来源和年度说明。
- “模板库”可查看内置模板。
- 自定义 JSON 量表优先于模板。JSON 必须包含有效维度、权重与说明；格式无效时不能开始批改。

量表是训练工具，不是官方评分细则。使用自定义量表前，建议确认各维度权重合计为 100%。

## 六、开始批改

点击“开始训练批改”后，软件会先做请求预检，并显示：

- 本次使用的教学方法或文章提炼方法；
- 将发送的题目、材料、原答与参考范围；
- 选择“仅精批”还是“精批＋修改稿”；
- 预计输出用量或费用提示。

确认后才调用模型。运行中可以取消任务；取消会停止本地等待，但服务端是否计费取决于模型服务商。

批改失败时，底部状态栏会显示原因。常见处理顺序：

1. 检查接口地址、模型名称和密钥。
2. 检查模型是否支持当前返回格式。
3. 缩短材料或原答，降低单次输出上限。
4. 在“未完成任务”中恢复上次工作区后重试。

## 七、阅读批改结果

“03 批改与对照”包含以下标签页：

### 复盘重点

显示本次最需要改进的项目和可直接执行的建议。优先改进按报告内容整理，不重新评分。

### 训练报告

显示审题、分项评价、材料证据和下一步训练建议。缺少题干或材料时，这里只提供表达与结构诊断，不显示完整题目总分。

### 评分依据

按维度列出分数来源、证据和核实状态。双击证据行可回到原答对应位置。单条批注不会单独改动总分；总分以报告中的维度评分为准。

表格会自动换行显示长批注。若列宽不合适，可拖动表头分隔线调整。

### 原答与批注

左侧是原答，右侧是批注列表。勾选批注后可执行“复核所选批注”。复核只核对所选条目，不重新评分，也不改动已有修改稿。

### 修改稿

- “保留原意修改”：尽量保留原答内容，只修正主要问题。
- “按题目重新组织”：按题目要求重新组织表达。
- “逐段修改对照”：对照原答与修改稿的段落变化。

修改稿不会改变原答得分。若本次只选择了精批，可稍后点击“生成修改稿（不重新评分）”；生成前同样会显示发送范围和预计用量。

### 导出

可导出 HTML、TXT、JSON 或 PDF 报告。导出内容来自当前已保存报告；导出前建议确认报告与批注已经生成完成。

## 八、文章资料库

“文章资料库”用于阅读、检索和核对原文。

1. 按主题、来源或关键词检索文章。
2. 打开文章查看正文与段落编号。
3. 选中需要提炼的文章。Ctrl 多选可一次选择多篇。
4. 点击提炼，确认发送范围后调用模型。
5. 提炼结果会保留来源与段落证据，供写作方法库核验。

文章原文保存在本机。检索和阅读不调用模型；只有主动提炼时才发送所选文章内容。

## 九、写作方法库

“写作方法库”分为文章提炼方法和教学来源方法。

- 文章提炼方法至少需要两篇不同正文支持。
- 每条方法都应能追溯到原文、来源或教学材料。
- 启用前检查证据、适用题型和使用边界。
- 可停用、比较或查看来源；停用不会删除历史记录。

方法辅助只提供写作思路，不会替你编造材料。批改时是否使用方法，会在开始前的确认框中列出。

## 十、训练记录、题库与复盘

### 训练记录

保留每次提交的原题、原答、训练评分、批注和修改稿。

- 可载入原题再次练习。
- 可查看历史报告并导出。
- 可添加人工评分，用于个人对照。
- 可删除当前记录或勾选后批量删除。

删除训练记录会同时删除绑定的人工评分，但保留题目。永久删除无法撤销，操作前会列出范围，默认取消。

### 我的题库

保存题目、材料、参考答案和草稿。每次已批改的作答独立保留，不会被下一次练习覆盖。

可保存当前题目、继续草稿或开始新作答。删除题目会清除该题专属草稿和参考要点，但保留已有训练报告及当前编辑文字。

### 复盘目标与复习

可将报告中的改进项加入复习，设置复习目标和完成状态。复盘目标用于自我管理，不参与评分。

## 十一、评测与方法对照

高级功能中的“评测”用于比较不同作答或模型输出，“方法对照”用于比较启用方法前后的差异。

- 本机评测与普通训练记录分开统计。
- 缺少独立人工评分时，只比较分数与波动，不计算准确性。
- 小样本结果不能代表模型整体水平，也不能替代真实阅卷。
- 对照实验会标明使用的方法、量表与提示版本。

## 十二、备份、恢复与卸载

在“设置”的备份区域可以：

- 手动创建备份；
- 创建带校验的安全备份；
- 从备份恢复；
- 设置自动备份目录与轮换数量；
- 打开备份所在目录。

自动备份只轮换超额且已登记的自动备份，手动备份和安全备份不会被自动删除。更换备份目录不会迁移或清理旧文件。

备份包含题目、原答、文章、方法、训练记录和设置，属于私密资料，默认不加密。请把备份放在可信位置；如设备共享，建议使用系统磁盘加密。

恢复备份前，软件会提示覆盖范围。恢复操作不可撤销，建议先另存当前数据。

卸载会清理安装目录和默认数据目录。范围外的备份、导出的报告和手动复制出去的文件会保留。

## 十三、快捷键

- `Ctrl+O`：导入题目或材料。
- `Ctrl+S`：保存当前草稿。
- `Alt+1`：训练批改。
- `Alt+2`：文章资料库。
- `Alt+3`：写作方法库。
- `Alt+4`：训练记录。
- `Alt+5`：我的题库。
- `Alt+6`：设置。
- `F1`：打开本使用说明。

## 十四、常见问题

### 为什么不能开始批改？

常见原因：未配置模型、密钥无效、量表 JSON 无效、字数或输出上限不合理、已有任务正在运行。底部状态栏会给出具体原因。

### 为什么没有总分？

缺少题干或给定材料时，软件只诊断表达与结构，不生成完整题目分数。补齐题目和材料后再批改。

### 修改稿会改变原答分数吗？

不会。修改稿是独立内容，原答得分保持不变。复核批注也不会重新评分。

### 图片识别不准怎么办？

在预览中直接修改识别文字，重点核对数字、专名、手写内容和段落顺序。必要时改用粘贴文字或 Word 导入。

### 模型调用失败会扣费吗？

软件在发送前显示预计用量，但实际计费由模型服务商决定。请求已到达服务端后取消，仍可能产生费用。

### 数据会上传吗？

本地阅读、检索、题库和旧报告不联网。只有你主动批改、提炼或复核时，软件才把完成该操作所需的内容发送给已配置的模型服务。

### 换电脑怎么迁移？

在旧电脑创建安全备份，把备份文件复制到新电脑，再在新电脑的“设置”中恢复。模型密钥通常不随备份迁移，需要重新填写。

## 十五、能力边界与重要说明

- 训练评分、分项评价和修改稿均由模型生成，未经真实阅卷校准。
- 材料要点是 AI 推断，不是官方采分点；引用应以原文为准。
- 模型可能遗漏、误判或生成不准确内容，提交前请自行核对。
- 软件不提供官方答案、考试报名或押题服务。
- 请勿在题目、原答或文章中填写身份证号、联系方式、账号密码等敏感信息。
- 使用第三方模型服务时，还需遵守该服务商的条款与隐私政策。

遇到无法恢复的错误时，请保留底部错误信息、操作步骤和当前版本号，再反馈问题。
