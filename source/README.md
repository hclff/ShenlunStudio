# 申论研习 0.9.5

Windows 64 位桌面软件。解压整个文件夹，双击 `ShenlunStudio.exe`。不要单独移动 EXE；旁边的 `_internal` 文件夹是运行所必需的。不需要安装 Python。

## 0.9.5 导入分配、量表模板库与训练目标

导入预览中的“分配内容…”按已核对原文的段落顺序显示来源、页码和全文。每段默认“不导入”，可分别指定题干与要求、给定材料、我的原答或参考答案，也可勾选后统一分配；右侧四栏分别预览，默认追加，可逐栏选择替换。替换非空栏时集中确认，默认取消；空目标不清空原栏。分配本身不自动识别题型、不改写文字、不请求模型。原有单栏导入、整题 JSON 替换及 OCR 上传确认继续使用。

“确认写入”在一个事务中归档导入前最新草稿并保存四栏；错误、超限或工作区冲突时整体回滚，保留编辑器和分配缓冲。对话框期间修改来源、编辑器或恢复数据库会使旧授权失效，须重新载入核对。检测到其他窗口草稿变化或恢复后，旧编辑器保留并暂停自动保存；关闭对话框后用“载入草稿”，明确确认放弃保留输入才载入当前数据库草稿。取消确认继续保留输入，不覆盖新状态。

量表区“模板库…”支持按名称与题型筛选，并提供“保存当前…”、“载入”、“复制”、“重命名”、“更新为当前内容…”和“删除…”。有效量表以原始 JSON 保存，格式空白、高精度数字、额外字段和维度 ID 保留；无效草稿可留在编辑器，不能入库。保存内置快照不改变当前模板身份；明确载入才复制到当前自定义草稿。重名拒绝覆盖，更新为当前内容是独立操作。载入覆盖已有自定义内容、更新和删除均需默认取消的确认。载入后的副本与库记录独立，之后编辑或删除库记录不影响该副本和旧报告；并发修改、删除或恢复会拒绝旧操作并保留输入，不重建记录。

已保存报告的复盘区“加入复习…”列出已有优先改进项，默认不勾选；选中后显示标题、行动建议及有效材料引用、原答批注摘录。仅向报告实际关联且仍存在的题目追加所选目标，重复加入去重；没有有效关联或摘要时入口不可用，不根据题名猜测或补建题目。复用已有计划的状态、日期与标签；“安排复习”中可查看目标、打开仍存在且评分依据匹配的本机来源报告或“移除所选目标”。状态始终手动确认，重练、看过报告或分数变化不自动标记已解决。来源报告删除后保留当时摘录并标注来源已删除；来源改变时标注不再匹配，不追改旧目标。删除题目则其计划和目标一起删除。保存检查恢复代际、计划版本、原报告依据和确切题目关联，冲突时保留勾选及输入，不部分写入。这些本机操作不产生付费模型请求。

模板和训练目标随普通、每日及安全 SQLite 备份保存。旧备份缺少模板表或目标仍可恢复；损坏内容在替换前拒绝。备份含题目、作答、模板和来源摘录等私密内容，未加密；自动备份设置与登记仍只属于本机。恢复会使已打开的可写窗口失效，需关闭并重新载入。来源摘录只保留必要本机证据，不保存模型密钥或完整配置。

源程序和打包程序的显式 `--smoke-test --data-dir <独立目录>` 都运行合成离线工作流探针，JSON 增加 `workflow`（`ok`、逐项 `checks`、`external_model_calls`、隔离 `data_dir`）；保留既有全部探针。该探针实际验证分配取消/提交/重启和历史、模板原文复制及隔离、目标去重与来源删除、含新数据与旧格式备份恢复，并在文字或图片模型调用前阻断请求。指定 `--screenshot` 时生成三个新对话框的正常、主窗口最小尺寸和实际有效最小尺寸截图。此探针验证这些具体流程，不代替并发边界测试和发布审查。

## 0.9.4 中断恢复、可视化量表与每日备份

“开始批改 → 未完成任务…”可查看、继续或放弃本机保存的批改任务。发送前保存题目、原答、实际量表、方法和参考依据快照；这些记录包含私密训练内容，随本机数据库及新备份保存，不包含 API 密钥或认证头。仅打开软件或任务列表不会调用模型。继续必须明确确认，默认取消；确认后使用当时的输入快照和当前已保存的模型与预算设置，可能再次计费。放弃不能继续该任务，但保留已保存的报告。

原答评分已经落库时，继续只生成修改稿，不重新评分、不改变原答评价；已完成任务直接打开报告。评分尚未保存时，上次请求在服务端是否执行未知，确认后从评分阶段重试，不能保证服务端恰好执行一次或不会重复收费。取消的任务也须明确选择继续，不会自动恢复收费请求。关联训练记录被删除、任务损坏或提示版本不兼容时拒绝继续。旧备份没有任务表仍能恢复，迁移时补建空表，不补造旧任务。

“参考与量表”默认显示维度名称、权重和说明表格，并保留“预览实际量表”。显示内置模板不会改变其来源；点击“编辑为自定义”后才可修改、添加或删除维度，已有维度改名保留 ID。切换考试、题型或模板不覆盖自定义内容，“恢复模板…”须确认。“高级 JSON…”打开或取消不改变草稿，确认时校验后同步表格。旧的无效或未完成 JSON 按原文保留，可保存并在重启后继续修复；未通过原有维度、权重合计等校验前不能批改。

“设置 → 每日自动备份”默认开启，每个本地自然日首次正常使用在界面初始化后后台备份，跨日持续打开时在后续空闲检查补做；不在每次启动或自动保存时重复复制。默认目录为本机数据目录下的 `backups`（正常安装为 `%LOCALAPPDATA%\ShenlunStudio\backups`），默认保留 7 份日常自动备份，可设置 1—30 份、关闭或选择目录。失败保留已有备份，可点击“重试今日备份”；更换目录不迁移或清理旧文件。只轮换超过份数且身份、目录和内容核验通过的已登记自动备份；不扫描删除其他文件，手动与恢复前安全备份不参加自动淘汰，需要自行管理。无法安全核验的文件可能使保留数量超过设置值。

“备份管理…”只显示本机登记的备份，可打开所在目录、恢复所选或“移除登记”（保留磁盘文件）。手动备份及恢复在后台执行；恢复仍须确认覆盖，并先生成安全备份，失败尝试回滚。备份包含题库复习计划、任务及其输入快照；恢复后不自动调用模型。登记和自动备份设置保存在本机独立清单，不随数据库还原；恢复文件不能借其中的路径指定本机自动写入目录，旧的外部路径须在当前机器明确选择。系统凭据库密钥不进入数据库备份，但备份含私密学习资料，未加密。

卸载清理安装及默认数据目录，范围外备份保留。确认完全卸载后，安装目录与 `%LOCALAPPDATA%\ShenlunStudio` 内的所有备份（包括其内部自选的备份目录）都会删除；只有位于这两个清理范围外的独立备份才会保留。安装标识、卸载确认和凭据清理行为沿用旧版。

## 0.9.3 复盘功能

- 训练报告顶部新增“优先改进”，从当次已保存报告整理最多三项，包括未覆盖的有据材料要点、原答批注或分项评价，不重新评分、不改变历史记录。材料引用会重新核对原文；点击带链接的批注可定位原答。导出 HTML、TXT 与 PDF 同样包含摘要。
- “批改与对照 → 逐段修改对照”可以切换两种修改稿，逐段显示新增、删除、改写与未改内容。按文本顺序对齐，不宣称语义一一对应；长段落采用整段标记，避免复杂比对卡顿。相关说明仅取自本次原答的对应批注与可核对材料引用，不推断每处改写原因；没有对应依据时明确说明。修改稿未生成时不把原答显示成全部删除。
- “我的题库 → 复习清单…”可按状态、日期和关键词筛选；选题后点击“安排复习…”填写问题标签、复习日期和待复习／复习中／已解决状态。已有“待重练”题目也显示在清单中。复习状态由用户手动确认，重练或分数变化不会自动解决问题；清单可直接开始新作答，保留旧草稿与报告。
- 以上处理均在本机完成，不额外调用模型。复习计划随题库备份恢复；删除题目同时删除其计划，但保留既有训练报告。多窗口修改同一计划时会拒绝覆盖，并保留编辑中的输入。旧版备份仍可恢复；恢复旧备份不会包含当时尚不存在的计划。升级安装保留本机数据，卸载仍按确认提示清理安装目录、本机数据与密钥。

## 添加与删除教学主体

在“写作方法库 → 教学方法 · 名师来源”点击“添加主体”，填写名称即可创建。自建主体可用于筛选、方法编辑以及批改时的指定来源或方法比较，重启与数据库备份恢复后保留。

在主体筛选中选中一个名字，点击“删除主体”。确认后，该主体及其下全部方法从当前列表移除，方法进入“已删除”，停止用于新批改；历史报告、方法版本和冻结评测保留，旧报告继续显示当时的主体名称。恢复其中的方法时会恢复对应主体，方法保持停用。主体增删不调用模型；任务运行或编辑内容尚未处理时不能直接变更。

## 模型 JSON 输出与调用上限

DeepSeek 等兼容接口使用设置中的“要求 JSON 对象输出”。普通批改、改写和文章提炼遇到空回复或无效 JSON 时，在剩余任务预算内最多自动重试一次，两次返回的用量分别记账。重复评分和方法对照评测保持原定单次请求，不自动改写提示重试。输出截断、仅返回推理内容、服务拒绝或拦截会分别显示原因；不补造缺失结果。

输入字符上限、单次输出 token 上限与任务 token 预算最多可设置为 `9,999,999`，默认值不变。它们是软件的可设置范围，服务商实际支持的上下文和输出上限仍以模型为准。任务预算需覆盖预计输入和输出；输出上限与任务预算都设到同一个最大值时，可能因没有余量容纳输入而停止调用。

“设置 → 一键检测兼容性”在确认后保存设置，分别检查连接、JSON 对象样例、所选输出参数与温度。每项使用固定测试内容、128 token 输出额度，单次超时最多30秒；不上传题目、材料或原答。检测可能产生少量费用，用量计入本机统计；取消可停止后续测试。通过只代表小额样例成功，不证明服务强制遵守 JSON Schema，也不证明填写的巨大输出额度可用。模型真实上限未获服务明确声明时显示“未知”；更改设置后会提示重新检测。已知的服务声明上限仅在当前会话内按接口、模型和输出参数匹配，不会静默修改用户数值。

批改发送前检查输入字符和首个请求的估算预留，预算需要另为后续修改稿及可能的重试留出余量。失败显示环节和建议，详情默认折叠；输入不清空。点击“重试本次任务”并确认后，使用失败时冻结的题目、原答、方法与依据，以及当前已保存的模型与预算设置重新执行，不使用后来在输入框中的改写，可能再次计费。如果原答评分已保存、仅修改稿失败，重试只重新生成修改稿，不重复评分。其他窗口更新或删除记录时不覆盖，不恢复已删除记录。0.9.4 起普通批改任务快照可跨重启保存，通过“未完成任务…”明确确认后继续；草稿与已保存报告仍保留。

## 删除训练记录与题库题目

0.9.1 在“训练记录”和“我的题库”中增加“删除当前项”与“删除勾选项”。点击名称查看单项，勾选框用于批量操作；“全选当前列表”只勾选当前显示的结果，“清空勾选”取消勾选。更换题库筛选后清空原勾选，刷新相同列表时保留仍存在的勾选。

删除前显示数量、名称及关联数据范围，确认窗口默认取消。确认后直接删除，不进入方法库的“已删除”列表；需要恢复时可使用删除前保存的数据库备份。删除训练记录同时清除它绑定的人工评分，题库题目仍保留。删除题目同时清除该题的题库草稿和参考要点版本，历史训练报告、报告内的要点快照及其人工评分仍保留，当前编辑中的文字也会保留为无题库关联的草稿。

任务运行期间不能删除；确认期间如选中的内容或关联数据发生变化，本次删除整体中止，需刷新核对后重试。删除不会改动独立评测集、冻结轮次或磁盘上已导出的报告。重启不会从保留的旧报告重新加入已删除题目；此后主动保存同一道题或重新提交训练可重新建立题库条目。新备份保存删除状态，恢复删除前的旧备份会回到当时的数据。

## 方法搜索、组合与对照评测

0.9.0 两个方法分页支持名称、步骤、检查项及来源关键词搜索，并可叠加题型、启用状态筛选；教学方法还可筛选主体。显示当前可见数和总数，批量全选只作用于当前结果。成功改变筛选后清空此前勾选；取消教学筛选切换时保留未保存编辑和原勾选。

“开始批改 → 管理组合…”可新建、编辑、删除常用组合，填写名称、适用题型，分别选择最多六项教学方法和六项文章方法；也可“载入当前勾选”，把方法库两页的当前勾选保存为一个组合。组合只保存名单，不自动审核或启用草稿；保存后如成员被删除，仍显示不可用成员，须明确移除或替换。每次使用检查全部成员的启用状态、题型与来源，不静默丢弃失效方法。

批改页可选“自动匹配”“关闭”或具体组合。“自动匹配”沿用原有方法辅助规则；“关闭”同时关闭教学和文章方法指导。“查看方法”按钮显示本次总项数，点击可查看确切名称、编号和教学版本；指定组合或关闭模式开始批改前再次确认实际名单，并冻结名单和来源供本次执行、保存与回看。删除正在使用的组合后关闭方法辅助，方法本身的启用状态和历史记录不改变。保存的报告也显示组合名称、版本及实际文章方法。

“小规模评测 → 方法对照评测”可把当前勾选的完整作答按同一模型、题干材料、参考要点和语料上下文，分别运行“关闭方法”与“指定组合”两组；重复次数沿用“重复评分与报告”页的设置。先显示两组合计调用次数和 token 估算，明确确认上传后才构造接口凭据并运行；可取消，部分结果仍保留。两组采用独立冻结轮次，不生成改写，也不写入普通训练记录。

报告列出配对答卷的均分、重复评分分差和未配对原因。两组未全部成功或实际模型/评分条件不同的答卷不纳入配对统计；只有来源为真实/公开作者作答且有独立、内容绑定人工评分时计算配对 MAE。没有人工对照显示样本不足，不把分数上涨、GPT 合成样本或机构示范当作准确率改善。可导出完整 JSON / HTML。备份包含组合及方法对照；旧版备份仍可恢复。

## 批量启用与停用方法

0.8.6 在教学方法和文章提炼方法列表中增加勾选框及批量工具栏。勾选需要处理的方法，或点击“全选当前列表”，再点击“批量启用…” / “批量审核启用…”或“批量停用…”。教学主体筛选后的全选只包含当前列表；切换筛选会清空此前勾选，刷新同一列表和执行批量操作会保留仍存在的方法勾选。点击名称仍用于查看和编辑单个方法，勾选与单项详情互不替代。

批量操作会先显示数量、方法名称及确认窗口，默认取消。教学方法批量启用需明确填写本地审核人和说明，每个成功启用的新版本分别记录该声明；文章方法沿用至少两篇不同正文及精确引文的核验。已处于目标状态的项目跳过，不重复追加教学版本；失效来源、缺少证据、删除或被其他窗口修改的项目不会被强行启用。结果窗口逐项显示成功、跳过、失败及具体原因，其他合格项目可继续完成。批量停用不改写历史报告或冻结评测。

有未保存的教学方法编辑时先保存或明确放弃；正在运行任务时批量操作不可用。启停在本机执行，不调用模型、不上传文章。当前批改仍按所选模式、题型和已启用方法解析，不因批量启用而一次发送全部方法。

## 彻底删除已删除方法

## 公开教学方法辅助

“写作方法库”分别管理期刊提炼卡与公开教学方法。在教学方法区域可查看、编辑来源、保存草案、核对后启用、停用和查看历史版本，也可预览导入／导出 JSON，或从本地资料导入来源摘录。启用需要填写本地审核者与核对说明；这里的审核者是你对资料的本地确认，不代表老师授权、亲自批改或软件认证。

内置登记白鹭、袁东、李梦圆、粉笔、站长申论（站长爱申论）、四海／飞扬、小马哥、张小龙、钟君、唐棣、单淑玲，共 11 个教学主体；人物与机构有明确区分。12 条公开方法草案来自其中有可核对正文或索引正文的部分来源，默认全部未启用。资料只读到课程目录、简介、学生笔记或无法读取正文的来源保持待核；没有把这些内容补写成“完整名师体系”。来源范围、短引文、适用题型与边界随方法显示；详细核验记录在随包“名师方法来源与边界”目录。

批改前可选择关闭、综合已启用方法、指定一个来源，或比较 2—3 个来源。每次最多选用 6 条适合当前题型的方法。指定来源缺少匹配的已启用方法时，会在模型调用前提示；综合模式没有可用方法时按原有流程批改。方法分析和共识／差异在同一次评分请求中生成，采用同一套量表，不生成多份“老师分数”或平均分；正常修改仍使用原有第二次请求。

评分依据始终是题干、给定材料、实际量表与已确认参考要点。方法应用需要引用本题材料，涉及原答引文时须能原样核实。报告展示实际采用的方法、来源范围、版本和本地审核信息，内容是模型生成的辅助分析。方法编辑后转为新草案，须重新核对启用；停用不会改写历史报告和已经冻结的评测输入。不同方法版本的成绩比较会提示条件不同，避免把评分条件变化当作训练进步。

JSON 导入只导入方法内容，所有启用和审核声明都会清除；与已有标识冲突的条目另存为新草案。更新软件保留已有用户数据库；新方法表随启动自动创建，旧版本备份仍可恢复。首次使用请先核对需要的方法再启用，并用已有人工评阅的少量题目检验实际效果。

## 考试类别与题型量表

“参考与量表”提供自动匹配、通用题型训练和手动选择。内置通用、国考中央/省级综合管理、国考市地级综合管理、国考行政执法、江苏 A/B/C 共七组框架，分别适配归纳概括、综合分析、提出对策、应用写作和文章写作，共 35 个训练模板。自动匹配需要填写考试和类别；无法匹配时说明原因并使用通用模板，不把其他省份的 A/B/C 直接当作江苏类别。

检查重点包括：概括区分做法与成效、合并重复并保留限定；分析按词句、评价、比较或关系任务组织；对策对应问题、主体和条件；应用文完成特定身份面向受众的沟通；文章检查主张、证据、分析和段落关系。类别侧重只在本题相关时使用，不强加无关法条、格式或固定题型。

可在批改前查看实际权重、检查说明、训练分档、能力参考来源与年度边界。自定义内容优先于模板；切换考试、题型或模板不会自动覆盖它。点击“编辑为自定义”后在默认表格中修改，或通过“高级 JSON…”编辑原始内容，软件将其作为自定义量表。未写完的 JSON 仍能自动保存，但须修正后才能批改或保存为有效题目模板。

批改记录保存实际量表、模板名称/版本和内容指纹；报告可核对每个维度的说明。UI 和服务重复校验不会改变已选择的模板，修改权重或说明后不会继续标成原内置模板。旧记录保留当时内容，不追溯套用新量表；新的模板来源版本也参与同题比较条件。

**内置模板的权重及分档都是软件设计的训练规则，未经真实阅卷校准，不是官方阅卷细则。** 自定义量表以用户提供的实际规则为准。公开大纲只提供能力要求，不能由此推断某类考试必考或不考某种题型。

本版能力参考基线：

- [2026 年国考公共科目大纲（国家林草局官方转载）](https://www.forestry.gov.cn/c/www/gsgg/645383.jhtml)：已核对搜索索引中的申论能力段落，直连全文超时；按该范围设计训练侧重。
- [江苏省 2026 年公共科目大纲（省公务员局）](https://www.jsxf.gov.cn/tzgg/art/2025/art_4b4f6c1ef283b21741ec26bc3c0ecc30.html)：正文已核对，分别参考 A 类综合分析和问题解决、B 类依法办事和公共服务、C 类基层落实、群众工作和应用写作。

其他年份或未填写年份时，界面与报告明确提示使用 2026 年能力框架作训练参考，不宣称已核验其当年度规则。手动模板与考试信息不符时也会提示。

## 保存、重练与复盘

- 在“开始批改”填好题干和材料后，打开“我的题库”点击“保存当前题目”。题库保存题干、材料、参考答案、考试信息和量表，可修改题名、来源与标签，按未练、已练、待重练筛选。同一题干、材料和题型归到同一题，修改材料会形成另一题；原答不混入题目模板。
- 停止编辑约一秒自动保存本机草稿，下次启动恢复；尚未写完的量表 JSON 也能保存。切题、载入其他内容和开始新作答时保留最近 20 份旧草稿，可通过“恢复最近草稿”找回。保存失败会明确提示，并阻止覆盖当前内容或退出，请先重试保存。
- “打开 / 继续草稿”接续该题未完成的原答。“开始新作答（清空原答）”保留题目设置并清空原答，旧草稿仍可恢复。一次批改是一条作答记录，生成修改稿不增加作答次数。升级后原有训练记录按题目自动归档。
- 在题目的作答列表按住 Ctrl 选择两次记录，比较完整原答、文字变化、材料要点覆盖与批注。模型及服务地址、提示版本、量表、满分、字数、调用参数、考试信息或参考资料不同，以及版本信息缺失时，不计算估分差；条件一致的估分差也不能证明真实学习增益。
- 在“训练记录”选中具体原答，点击“记录人工评分”，填写分数、理由、评阅人和是否来自独立人工阅卷。零分有效；独立标记是自行声明。原答、原 AI 分数或评分条件改动后，旧人工分标为待复核，并从误差统计中排除。人工分与同答案重复评分样本不足时，界面如实显示样本不足。

## 第一次使用

1. 打开“设置”，填写你所使用的模型服务提供的 HTTPS 接口根地址（通常以 `/v1` 结尾）、模型名称和 API 密钥，点击“一键检测兼容性”并确认。支持兼容 Chat Completions 且能够输出 JSON 的接口；可切换输出 token 参数和是否发送 temperature。服务费用按你的模型账号计费。
2. 在“开始批改”粘贴题干、给定材料和自己的答案，选择题型、满分、字数限制。补充考试年份、类别和自定义评分量表后，点击“开始训练批改”。没有题干或材料时仅做诊断，不生成分数。
3. 在结果中核对材料要点、原文引用、答案批注和维度得分。原答评分先保存，修改稿另行生成；修改失败不会覆盖原答评分。“训练记录”可重新打开并导出 HTML、TXT、JSON 或 PDF。
4. 在“文章资料库”检索并选中文章，点击提炼，确认预估用量后开始。候选方法先保存在“写作方法库”，核对出处及适用边界后手动启用。同一方法至少需要两篇不同正文的真实引用，才能成为通用批改辅助方法。提炼支持断点续做。

## 人工参考要点与小规模评测

在“我的题库”选中已保存题目，打开“人工参考要点…”。按材料段落 M1、M2 等填写要点及逐字原文引用；可保存草稿、填写确认者后确认，或说明理由撤回。所有版本保留，保存新草稿不影响此前已确认版本。它是训练参考，不是官方采分标准。批改时仅使用与题干、材料及题型一致的已确认版本，并在报告中固定该版本和逐点覆盖证据；换版本后的训练记录不直接计算进步幅度。

“我的题库 → 小规模评测…”中可新建评测集、添加当前原答、手动粘贴或预览导入 JSON。须标明真实获授权作答、公开作者自答、GPT 受控样本、机构示范或来源未确认；摘录与待补全内容不能参与完整评分。同一题的不同作答一起划入开发集或留出集。每集最多100份，每份可重复1—5次，默认3次。

先导出盲评 HTML/JSON，人工独立评阅后填写分数、理由和评阅人，再导入或在软件中逐份保存。未填写与零分区分保存；独立评阅标记为评阅者声明。联网运行前会显示模型、地址、调用次数及 token 估算，确认后才读取密钥并开始。每次只评分原答，不生成修改稿、不写入日常训练记录；取消保留已完成单元，迟到结果不记成功。每轮固定题目、原答、参考要点、语料片段、方法与模型参数。

报告按实际评分条件计算同一答案的重复波动。只有真实或公开自答且绑定有效独立人工标签的样本参与误差统计；GPT 对照与机构示范另列。没有有效人工对照时，MAE 显示样本不足，不用 AI 分数冒充人工分。

随包“公开作答来源索引/index.html”整理本轮检索：1篇可阅读原帖中的7个作者自答位置、其他待核线索及定性观察。目前可直接批量运行且完整可复用的真实作答为0份，独立人工评分为0条；这些索引不是可导入题库，不代表已完成真实评分校准。既有10题30份GPT控制作答仍保持原来源。

- 图片和扫描页默认在本机调用 Windows 10/11 OCR，优先使用中文组件；本机识别不需要 API 密钥。增强模式保留原图尺寸，长截图分段识别，支持双栏先左后右；先保留字形，仅在空结果时重试对比度与锐化，检测到轻度倾斜时最多纠偏重试一次。标准模式保留单次缩图识别方式。若系统未安装中文 OCR，图片仍可保留在预览中供人工修订或可选 AI 识别。
- 原图支持放大查看、顺时针旋转与框选区域，当前页可重新进行本机识别，或选择“AI 转写…”。AI 使用设置中的兼容接口，模型须支持图像输入。调用前显示所选页/区域、模型与地址、图像尺寸及 token 估算，只有再次确认后才上传；只发送当前选中的图像区域，去除元数据并限制大小，不自动上传其他页面。长图建议先裁剪；取消后已经发出的请求仍可能计费。
- 重试结果先作为候选显示，与现有修订文字对照；明确采用后才更新预览，可撤销最近的采用。识别失败、取消或关闭预览不会覆盖练习中的原文。数字、专名、表格阅读顺序和手写内容仍需人工核对；软件不提供逐字可信度，不能保证手写识别准确。
- 读取前可指定 PDF 页码（如 `1-3,5`）；范围对本次每份 PDF 分别生效。文字层乱码或只有标题、水印时，勾选“PDF 全部使用本机 OCR”。最多 20 个文件、单个 25 MB，每份 PDF 最多选 40 页，每批最多 80 页、25 万字符；图片限 2400 万像素，原图与预览缓存合计最多 96 MB，增强模式单页最多 12 段，超限会说明并提示分批或裁剪。
- 预览可勾选页面、修改文字、上移/下移或移除，并对照 PDF/图片原页。选择写入题干、材料、原答或参考答案，默认追加到已有内容；勾选替换后才覆盖该栏。取消不会改动已有练习，读取失败的文件会单独列出。
- 结构化 JSON 题库可逐题选择，支持题干、材料、原答、参考、考试/年份/类别、题型、满分、字数上限和自定义量表。单条记录可选择“整题替换”，届时缺失字段会按表单默认值重置，缺失原答会清空；默认只导入选中的一栏。只有明确确认后才写入。

## 评分的含义

评分量表为训练用途，并非官方阅卷细则。给定材料、题干任务和答案证据优先，文章的语言风格仅作辅助，不能把“像社论”直接当作申论高分。软件没有完成真实阅卷分数校准。可在“训练记录”绑定具体记录的人工分，或导入人工评分 CSV/JSON，查看样本数、平均绝对误差、偏差、均方根误差、相关性和重复评分波动。界面标明绑定人工分数量，误差统计包含导入及绑定的有效样本；同一答案、同一评分条件的至少两次记录才计算软件内的重复评分波动。

人工校准记录字段为 `human`、`ai`、`max_score`，可选 `answer_id`（同一答案重复评分需相同）、`version`。例如：

```csv
answer_id,human,ai,max_score,version
exercise-001,14,15,20,custom-model-v1
exercise-001,14,14.5,20,custom-model-v1
```

## 数据与密钥

默认数据目录为 `%LOCALAPPDATA%\ShenlunStudio`，数据库文件为 `studio.db`。首次运行复制内置资料，后续运行保留你的资料、题库、草稿和历史；更新软件不会自动替换已有数据库。也可用命令行 `ShenlunStudio.exe --data-dir "D:\我的申论数据"` 指定目录。

在“设置”使用“备份数据库…”可生成包含尚未合并日志的完整 SQLite 备份。“从备份恢复…”需要所有任务结束并确认覆盖，软件会先保存当前草稿、检查备份结构和完整性，再在数据目录生成“恢复前备份-…”安全副本；恢复失败会尝试回滚。兼容 0.3 数据库并自动迁移题库。备份含本地资料、草稿、训练和普通设置，API 密钥仍在凭据管理器，不随数据库备份。手动复制数据目录前请关闭软件。

密钥优先保存到 Windows 凭据管理器；不可用时仅在当前进程内保留，并提示未永久保存。密钥不写入普通数据库设置或导出报告。点击批改会把该题题干、材料、答案和最多 8 个本地参考段落，以及本次采用的已确认要点和方法来源摘要发送给你配置的模型；启用教学方法时还包括来源短引文、方法版本和本地审核声明。点击文章提炼发送选中文章正文。阅读、检索、草稿与历史查看在本地完成。

可选 AI 图像转写也使用上述模型配置与密钥管理；它只转写可见文字，无法辨认处应标记，不用于直接解题、评分或润色。用量与 token 预算是辅助控制，服务端未返回用量时以估算值记录。取消阻止后续处理，但已经发出的请求可能继续在服务端执行和计费。

## 发行内容与重建

发行包**不包含应用源码**：安装目录只有可执行程序、运行库、第三方许可证、使用说明、方法手册与界面预览。依赖许可证位于 `THIRD_PARTY_LICENSES`；Qt/PySide6 以 LGPLv3 动态链接方式分发，附上游源码地址，这些库保持可替换。本应用自身源码不在安装包内。

可执行程序由打包工具把编译后的字节码封入程序归档，因此安装目录里没有明文 `.py` 文件；这不等于"不可反编译"，专用工具仍可解析归档内容。

重建需要向发布者获取源码与 `assets/seed.db`（语料另有出版方权利，不在发行包内提供）。开发环境使用 Python 3.13；源码支持 Python 3.11 以上。

```powershell
python -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements-build.txt
.venv/Scripts/python.exe -m pytest -q
.venv/Scripts/python.exe scripts/build_release.py
```

`scripts/build_release.py` 先在 `build-tmp/pyi-dist` 生成打包器的原始输出，再由 `scripts/stage_release.py` 按白名单装配 `dist/ShenlunStudio`；白名单之外的文件（源码、测试、构建残留、审计资料）不会进入发行目录。`scripts/verify_release.py` 会反向断言发行目录不含 `*.py`、测试目录与多余数据库，并核对 `build-info.json` 记录的源文件哈希。

原始期刊清单可通过 `scripts/seed_corpus.py --help` 导入。`scripts/seed_people.py` 可重新导入上述人民日报采样日。
